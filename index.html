How to type maths

  • Use * for multiplying: 2*x, never 2x. Between letters too: x*y.
  • Powers: x^2. Division: 1/2. Brackets matter: x^9+5 is not x^(9+5).
  • Everything in lowercase. Functions: sin(x) cos(x) tan(x) sqrt(x) abs(x) ln(x) exp(x). Also e and pi, like e^(2*x).
  • Arbitrary constants: use c when there is one. When there are two or more, use c1, c2, c3 ...
  • If y = (or similar) is already in front of the box, type only what comes after it. If the question asks for an equation, type the whole thing with an = sign.
  • The box under your answer shows how the app read it. Check it before pressing Check.
